# Authored low parry v1

Eight playable characters receive six-frame low-parry supplements:40new generated deflection/recovery frames plus8shared settled recovery frames. Built-in imagegen was used with each preserved idle and crouched reference. Raw generations, references and exact prompts are preserved in each character directory.

The standalone Pillow packer scripts/pack-authored-low-parry-v1.py uses one uniform scale per character derived from its generated calm frame, aligns shoe/foot soles to the approved crouch reference, and copies reference-settle.png as frame5. Lossless WebP decode must match that last frame byte-for-byte RGBA; all six cells must be unique. No project pose-analysis module or root pose cache is imported.

All runtime strips are2304×448(6cells384×448), deferred at HD quality. Source/reference/prompt/runtime hashes and full-stage byte totals/caps are recorded in the manifests. Existing art and gameplay/mapper code are unchanged. The renderer selects crouch-parry only for grounded crouched parry, keeps standing/Lite/failed-texture fallbacks, and shares the final cell with held neutral crouch.
