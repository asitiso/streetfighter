# ============================================================

# ============================================================
# 9. PARRY SYSTEM
# ============================================================

Parry는 이 게임의 가장 중요한 시스템 중 하나다.


HIGH PARRY:

공격 직전 Forward 입력.


LOW PARRY:

공격 직전 Down 입력.


성공 시:

Damage 0

Parry VFX

Parry SFX

짧은 freeze

즉시 행동 가능

공격자 recovery 유지


BELT MODE에서도 동일한 시스템을 사용한다.

예:

Enemy A 공격
→ Parry

Enemy B 공격
→ Parry

Enemy C Low Attack
↓ Parry

→ Counter Attack

이 가능해야 한다.


RED PARRY도 구현한다.

Guard 중 정확한 타이밍의 Parry 입력으로
즉시 반격 기회를 만든다.

Red Parry는 고급 기술이며
게임 진행 필수 요소로 강요하지 않는다.

활용 범위만 확대한다.


# ============================================================
# 13. SOFT LANE ALIGNMENT
# ============================================================

SF3 기술은 기본적으로 한 축 싸움에 맞춰져 있다.

BELT MODE에서 Y축 때문에 공격이 지나치게 자주 빗나가면
조작감이 나빠진다.

따라서 공격 직전 가까운 적에 대해

SOFT LANE ALIGNMENT

를 적용한다.

그러나 자동 이동처럼 느껴지면 안 된다.

매우 짧은 거리만 허용한다.

No Teleport.

No Hard Lock.

No Forced Snap.

# 15. BELT → DUEL TRANSITION
# ============================================================

이 게임을 대표하는 장면으로 취급한다.

플레이어 캐릭터가 자동으로 그 방향을 바라본다.

카메라가 낮아지고 가까워진다.

적들이 뒤로 물러난다.

캐릭터 클로즈업.

Boss 클로즈업.

HP HUD가 DUEL HUD로 변한다.

"FIGHT!"

대전 시작.


전환 카메라 패턴을 최소 3종 이상 제작해
5개 Stage가 모두 동일한 연출처럼 보이지 않게 한다.

# ============================================================
# 31. VISUAL PRODUCTION — ABSOLUTE RULE
# ============================================================

이 프로젝트는 VISUAL-FIRST로 진행한다.


필요한 그래픽 에셋이 없다는 이유로

회색 박스

흰 사각형

기본 HTML 버튼

임시 원

색깔만 있는 Placeholder

를 최종 화면처럼 남겨두지 마라.


필요한 이미지가 없으면
필요한 이미지를 적극적으로 제작한다.


순서:

게임에 필요한 화면 확인

↓

Visual Reference 제작

↓

게임용 asset 제작

↓

Sprite / Background / UI / FX 분리

↓

실제 게임 적용

↓

스마트폰 화면 캡처

↓

Reference와 비교

↓

부족하면 다시 제작


"나중에 그림을 넣는다."

라는 방식으로 미루지 않는다.

외부 인증이 필요한 작업

등 정말 진행 불가능한 경우에만 질문한다.


기존 코드를 먼저 분석한다.

작동하는 코드를 무조건 다시 쓰지 않는다.

중복 시스템을 만들지 않는다.

완성된 기능을 다음 PHASE에서 깨뜨리지 않는다.


각 PHASE 종료 시:

1. 구현 내용
2. 실제 변경 파일
3. 테스트 결과
4. 아직 남은 문제
5. 다음 PHASE 진행 내용

을 짧게 기록하고 즉시 계속한다.
